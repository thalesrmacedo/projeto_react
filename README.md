## Estrutura do Projeto

Crie a seguinte estrutura dentro de `src`:

```text
src/
├── components/
│   ├── Resumo.jsx
│   ├── Formulario.jsx
│   ├── ListaTransacoes.jsx
│   └── Grafico.jsx
├── App.jsx
├── App.css
├── index.css
└── main.jsx
```

## Instalação das dependências

```text
cd dashboard-financas
npm install
npm install recharts
npm run dev
```
